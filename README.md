# 소우주 AI 말 연구소 🤖

초등학생을 위한 AI 리터러시 교육 게임입니다.
code.org의 "AI for Oceans"처럼, 학생이 직접 아기 로봇 **소우주**에게 좋은말과 나쁜말을 가르치고
그 결과를 관찰하며 인공지능의 원리를 몸으로 배웁니다.

## 특징

- **진짜 학습**: 미리 정해진 연출이 아니라, 브라우저 안에서 나이브 베이즈 분류기가
  학생이 라벨링한 글자 무늬를 실제로 학습합니다. 엉터리로 가르치면 정말 엉터리가 됩니다.
- **학습 과정의 가시화**: 라벨링하면 글자 조각이 로봇 두뇌로 날아가고,
  판정할 때마다 근거 글자와 확신도 게이지를 보여줍니다.
- **14단계 커리큘럼**: 관찰 실험 → 훈련 → 두뇌 들여다보기 → 무늬 실험(일반화·함정) →
  분류 시험 → 거꾸로 실험(AI 편향) → 마음 가르치기 → 졸업 시험 → 내 말 챌린지 → OX 퀴즈 → 수료증
- **발견 카드 8장**: 단계마다 AI 핵심 개념을 카드로 수집
- **수료증 발급**: 이름·점수·별점이 담긴 수료증을 PNG로 저장

## 배우는 개념

1. AI는 배우기 전엔 아무것도 모른다 (데이터의 필요성)
2. 비슷한 무늬는 알아본다 (일반화)
3. AI는 뜻을 모른다 (패턴 인식의 한계)
4. 데이터가 많을수록 정확해진다
5. AI는 가르친 사람을 닮는다 (편향)
6. 사람마다 기준이 다르다 (다양한 데이터의 중요성)
7. AI는 피드백으로 계속 자란다

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 서버·로그인·API 불필요.
